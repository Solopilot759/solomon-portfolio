Venjix UI.

A desktop AI chatbot interface designed to provide a clean and modern conversational experience.

OVERVIEW

Designing the experience.

Venjix is an AI chatbot project focused on creating a polished desktop interface around conversational AI.

The project includes a structured authentication experience, account creation, email verification, voice setup, welcome screens, chat history, and the main conversational interface.

I worked on the user interface and application experience using Python and PySide6, with the goal of creating an interface that feels familiar while still having its own identity.
